**Edit 3 — Add new methods to the GiftPage object:**

Add the following three methods to the GiftPage object (after `_onAuthSuccess` and before the closing `}`):

```javascript
    _fetchFreshCsrfToken() {
        return fetch('/csrf-token')
            .then(r => r.json())
            .then(data => {
                if (data.token) {
                    window._currentCsrfToken = data.token;
                    // Also update authModal dataset so repeated uses work
                    const modalEl = document.getElementById('authModal');
                    if (modalEl) modalEl.dataset.csrfToken = data.token;
                }
            })
            .catch(() => {
                // Non-fatal: CSRF will fall back to authModal.dataset.csrfToken
                console.warn('[GiftPage] /csrf-token fetch failed');
            });
    },

    _onReserveSuccess(giftId, availableQty, isExhausted) {
        // Update the card DOM
        const card = document.querySelector(`.btn-choose-gift[data-gift-id="${giftId}"]`)
                              ?.closest('.card');
        if (card) {
            const qtyEl = card.querySelector('[data-qty]');
            if (qtyEl) qtyEl.textContent = availableQty;
            if (isExhausted) {
                const footer = card.querySelector('.card-footer');
                if (footer) {
                    footer.innerHTML = '<button class="btn btn-secondary w-100" disabled>Indisponível</button>';
                }
                card.classList.add('gift-card--esgotado');
            }
        }

        // Show Bootstrap Toast
        const toastEl = document.getElementById('reserveToast');
        if (toastEl) {
            bootstrap.Toast.getOrCreateInstance(toastEl).show();
        }
    },

    _onReserveError(giftId, message) {
        // Mark card as exhausted on the assumption it's now unavailable
        const card = document.querySelector(`.btn-choose-gift[data-gift-id="${giftId}"]`)
                              ?.closest('.card');
        if (card) {
            const footer = card.querySelector('.card-footer');
            if (footer) {
                footer.innerHTML = '<button class="btn btn-secondary w-100" disabled>Indisponível</button>';
            }
            card.classList.add('gift-card--esgotado');
        }

        // Show error toast
        const toastEl     = document.getElementById('reserveToast');
        const toastBody   = document.getElementById('reserveToastBody');
        const toastHeader = document.getElementById('reserveToastHeaderText');
        if (toastEl) {
            if (toastHeader) toastHeader.textContent = 'Atenção';
            if (toastBody)   toastBody.textContent   = message;
            bootstrap.Toast.getOrCreateInstance(toastEl).show();
        }
    },
```

IMPORTANT: Ensure the last method added does not have a trailing comma if it is the last member of the object literal. Check the surrounding syntax carefully when editing.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser JS → POST /reserve | gift_id and csrf_token are read from JS variables and DOM; stale token causes 403 |
| GET /csrf-token | Returns a new session-bound CSRF token; no auth required on the endpoint itself (token is session-scoped) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Tampering | Stale CSRF token in DOM after login causes 403 on /reserve | mitigate | `_fetchFreshCsrfToken()` fetches `/csrf-token` before re-click; stores in `window._currentCsrfToken` |
| T-03-10 | Tampering | JS constructs gift_id from DOM data attribute — could be tampered by user in DevTools | accept | Server validates `(int)$_POST['gift_id'] > 0` and checks `is_active=1`; DOM value is only a convenience, not trusted |
| T-03-11 | Information Disclosure | Toast body exposes raw server error strings | accept | Server error strings are intentionally user-facing (e.g. "Esse presente acabou de ficar indisponível.") — no internal details exposed per SEC-07 |
</threat_model>
