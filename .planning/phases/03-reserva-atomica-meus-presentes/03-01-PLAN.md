Create `app/Models/ReservationModel.php`:

```php
<?php
declare(strict_types=1);

namespace App\Models;

class ReservationModel extends BaseModel {

    /**
     * Atomically reserve a gift for a user.
     * Uses SELECT ... FOR UPDATE to prevent concurrent over-reservation (STOCK-03..05, D-17).
     *
     * @return array{success:bool, available_qty?:int, is_exhausted?:bool, error?:string}
     */
    public function reserve(int $giftId, int $userId): array {
        $db = $this->getDb();
        try {
            $db->beginTransaction();

            // Lock the gift row for this transaction — prevents concurrent decrement below 0
            $stmt = $db->prepare(
                'SELECT id, available_qty FROM gifts WHERE id = :id AND is_active = 1 FOR UPDATE'
            );
            $stmt->execute([':id' => $giftId]);
            $gift = $stmt->fetch();

            if (!$gift || (int)$gift['available_qty'] <= 0) {
                $db->rollBack();
                return ['success' => false, 'error' => 'Esse presente acabou de ficar indisponível.'];
            }

            $db->prepare(
                'INSERT INTO reservations (user_id, gift_id, quantity, status, created_at)
                 VALUES (:uid, :gid, 1, :status, NOW())'
            )->execute([':uid' => $userId, ':gid' => $giftId, ':status' => 'reserved']);

            $db->prepare(
                'UPDATE gifts SET available_qty = available_qty - 1, updated_at = NOW()
                 WHERE id = :id'
            )->execute([':id' => $giftId]);

            $db->commit();

            $newQty = (int)$gift['available_qty'] - 1;
            return [
                'success'       => true,
                'available_qty' => $newQty,
                'is_exhausted'  => $newQty <= 0,
            ];

        } catch (\Exception) {
            if ($db->inTransaction()) {
                $db->rollBack();
            }
            // SEC-07: never expose exception message in production
            return ['success' => false, 'error' => 'Erro ao processar reserva.'];
        }
    }

    /**
     * Return all reservations for a user, joined with gift data (RESERVE-03, D-11).
     *
     * @return array<int, array{id:int, gift_id:int, quantity:int, status:string, created_at:string,
     *                          gift_name:string, category:string, image_path:string|null}>
     */
    public function findByUserId(int $userId): array {
        return $this->query(
            'SELECT r.id, r.gift_id, r.quantity, r.status, r.created_at,
                    g.name AS gift_name, g.category, g.image_path
             FROM reservations r
             JOIN gifts g ON g.id = r.gift_id
             WHERE r.user_id = :uid
             ORDER BY r.created_at DESC',
            [':uid' => $userId]
        )->fetchAll();
    }

    /**
     * Fetch a single reservation, verifying ownership (prevents IDOR, V4).
     *
     * @return array<string,mixed>|false
     */
    public function findByIdAndUser(int $id, int $userId): array|false {
        return $this->query(
            'SELECT * FROM reservations WHERE id = :id AND user_id = :uid LIMIT 1',
            [':id' => $id, ':uid' => $userId]
        )->fetch();
    }

    /**
     * Cancel a reservation and return stock atomically (D-12, RESERVE-03).
     *
     * @return array{success:bool, error?:string}
     */
    public function cancel(int $id, int $userId): array {
        $db = $this->getDb();
        try {
            $db->beginTransaction();

            $stmt = $db->prepare(
                'SELECT id, gift_id, status FROM reservations
                 WHERE id = :id AND user_id = :uid FOR UPDATE'
            );
            $stmt->execute([':id' => $id, ':uid' => $userId]);
            $res = $stmt->fetch();

            if (!$res || $res['status'] !== 'reserved') {
                $db->rollBack();
                return ['success' => false, 'error' => 'Reserva não encontrada ou não cancelável.'];
            }

            $db->prepare(
                'UPDATE reservations SET status = :status WHERE id = :id'
            )->execute([':status' => 'cancelled', ':id' => $id]);

            $db->prepare(
                'UPDATE gifts SET available_qty = available_qty + 1, updated_at = NOW()
                 WHERE id = :gid'
            )->execute([':gid' => $res['gift_id']]);

            $db->commit();
            return ['success' => true];

        } catch (\Exception) {
            if ($db->inTransaction()) {
                $db->rollBack();
            }
            return ['success' => false, 'error' => 'Erro ao cancelar reserva.'];
        }
    }
}
```

**Step B — app/Controllers/ReservationController.php:** Create with 4 actions:

```php
<?php
declare(strict_types=1);

namespace App\Controllers;

use App\Helpers\Flash;
use App\Helpers\View;
use App\Middleware\AuthMiddleware;
use App\Middleware\CsrfMiddleware;
use App\Models\ReservationModel;

class ReservationController {

    /**
     * POST /reserve — Atomic gift reservation (STOCK-01..05, RESERVE-01, RESERVE-02).
     * CsrfMiddleware::validate() is already called by Router before this method runs.
     */
    public function store(array $params = []): void {
        header('Content-Type: application/json');

        // V2: session-based auth check — guest role required
        if (($_SESSION['role'] ?? '') !== 'guest') {
            echo json_encode(['error' => 'É necessário estar autenticado.']);
            exit;
        }

        $giftId = (int)($_POST['gift_id'] ?? 0);
        if ($giftId <= 0) {
            echo json_encode(['error' => 'Presente inválido.']);
            exit;
        }

        $result = (new ReservationModel)->reserve($giftId, (int)$_SESSION['user_id']);

        echo json_encode($result);
        exit;
    }

    /**
     * GET /my-gifts — Reservation list for authenticated guest (RESERVE-03, D-09..D-13).
     */
    public function myGifts(array $params = []): void {
        AuthMiddleware::requireGuest();   // redirects to /gifts if not authenticated

        $reservations = (new ReservationModel)->findByUserId((int)$_SESSION['user_id']);

        View::render('public/my-gifts/index', [
            'title'        => 'Meus Presentes',
            'reservations' => $reservations,
        ]);
    }

    /**
     * POST /my-gifts/cancel — Cancel a reservation and return stock (D-12).
     * CsrfMiddleware::validate() already called by Router.
     */
    public function cancel(array $params = []): void {
        AuthMiddleware::requireGuest();

        $reservationId = (int)($_POST['reservation_id'] ?? 0);
        if ($reservationId <= 0) {
            Flash::set('error', 'Reserva inválida.');
            header('Location: /my-gifts');
            exit;
        }

        $result = (new ReservationModel)->cancel($reservationId, (int)$_SESSION['user_id']);

        if ($result['success']) {
            Flash::set('success', 'Reserva cancelada com sucesso.');
        } else {
            Flash::set('error', $result['error'] ?? 'Erro ao cancelar reserva.');
        }

        header('Location: /my-gifts');
        exit;
    }

    /**
     * GET /csrf-token — Returns fresh CSRF token as JSON.
     * Solves the stale-token pitfall: after login, the session token is rotated
     * (_onAuthSuccess must fetch this before POSTing to /reserve).
     */
    public function csrfToken(array $params = []): void {
        header('Content-Type: application/json');
        echo json_encode(['token' => CsrfMiddleware::token()]);
        exit;
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST /reserve | gift_id is user-controlled input; user might not be authenticated |
| Browser → POST /my-gifts/cancel | reservation_id is user-controlled; user could attempt to cancel someone else's reservation |
| Browser → GET /my-gifts | unauthenticated users must be blocked at the application layer |
| MySQL transaction | concurrent requests race to decrement available_qty |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | POST /reserve — gift_id manipulation | mitigate | Cast `(int)($_POST['gift_id'] ?? 0)`, validate `> 0` before DB query; prepared statement parameter |
| T-03-02 | Tampering | POST /my-gifts/cancel — IDOR (cancel another user's reservation) | mitigate | `WHERE id = :id AND user_id = :uid` in cancel() query — ownership verified before UPDATE |
| T-03-03 | Tampering | available_qty race condition (concurrent reserve of last unit) | mitigate | `BEGIN → SELECT ... FOR UPDATE → check qty > 0 → UPDATE → COMMIT`; ROLLBACK if qty = 0 |
| T-03-04 | Tampering | CSRF on POST /reserve and POST /my-gifts/cancel | mitigate | `CsrfMiddleware::validate()` called by Router for all POST routes before controller runs |
| T-03-05 | Elevation of Privilege | Unauthenticated POST to /reserve | mitigate | `$_SESSION['role'] !== 'guest'` check at top of `store()` before any DB operation |
| T-03-06 | Elevation of Privilege | Unauthenticated GET /my-gifts | mitigate | `AuthMiddleware::requireGuest()` called as first statement in `myGifts()` and `cancel()` |
| T-03-07 | Information Disclosure | PDO exception message exposed in reserve/cancel error response | mitigate | Catch `\Exception`, never return `$e->getMessage()`; return generic string only |
| T-03-08 | Tampering | Stale CSRF token causes 403 on first-time reservation after login | mitigate | GET /csrf-token endpoint; _onAuthSuccess fetches fresh token before POST /reserve |
</threat_model>
