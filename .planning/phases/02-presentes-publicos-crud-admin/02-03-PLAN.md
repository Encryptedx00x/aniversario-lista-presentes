```php
<?php
declare(strict_types=1);

namespace App\Controllers;

use App\Models\GiftModel;
use App\Helpers\View;

class GiftController {

    public function index(array $params = []): void {
        $giftModel = new GiftModel;
        $gifts     = $giftModel->getAllActive();

        // Build distinct category list for the filter dropdown
        $categories = array_values(array_unique(
            array_filter(array_column($gifts, 'category'))
        ));
        sort($categories);

        View::render('public/gifts/index', [
            'title'      => APP_NAME . ' — Lista de Presentes',
            'layout'     => 'main',
            'gifts'      => $gifts,
            'categories' => $categories,
        ]);
    }

    public function filter(array $params = []): void {
        $search   = trim($_GET['search']   ?? '');
        $category = trim($_GET['category'] ?? '');
        $sort     = $_GET['sort'] ?? 'available';

        // Whitelist sort values — never pass raw user input to ORDER BY
        $allowedSorts = ['available', 'price_asc', 'price_desc', 'featured'];
        if (!in_array($sort, $allowedSorts, true)) {
            $sort = 'available';
        }

        $gifts = (new GiftModel)->filter($search, $category, $sort);

        // Render PARTIAL ONLY — not a full page. Do NOT use View::render() here.
        $e = fn($v) => htmlspecialchars((string) $v, ENT_QUOTES, 'UTF-8');
        require ROOT_PATH . '/app/Views/public/gifts/_cards.php';
        exit;
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL/GET params → GiftController::filter() | search, category, sort values from user |
| PHP Session → HTML output | $_SESSION['user_id'] rendered into data-logged-in attribute |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering | XSS via gift fields in public cards | mitigate | _cards.php uses $e() on all gift['name'], gift['description'], gift['category'], gift['price'] |
| T-02-11 | Tampering | SQL injection via /gifts/filter GET params | mitigate | GiftController::filter() whitelists sort param; GiftModel::filter() uses named PDO params for search and category |
| T-02-12 | Information Disclosure | User session state in HTML | accept | data-logged-in is '1' or '0' — no PII exposed; session data never written to page |
| T-02-13 | Tampering | CSRF on auth modal fetch POSTs | mitigate | data-csrf-token rendered at page load from CsrfMiddleware::token(); JS reads it and includes in FormData body before each fetch |
</threat_model>
