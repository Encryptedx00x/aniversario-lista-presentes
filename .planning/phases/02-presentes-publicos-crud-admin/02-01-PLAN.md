**Router extension (app/Router.php):**

Replace the `dispatch()` method to support `{param}` placeholders. The new dispatch must:
1. First try exact match (existing behavior — no regression).
2. If no exact match, iterate route keys and test each as a pattern where `{param}` becomes a named capture group `(?P<param>[^/]+)`.
3. If a pattern matches, extract the captured params into an array and pass it as the first argument to the controller action.
4. If no pattern matches, call `(new ErrorController)->notFound()`.

Exact replacement for `app/Router.php`:

```php
<?php
declare(strict_types=1);

use App\Middleware\AuthMiddleware;
use App\Middleware\CsrfMiddleware;
use App\Controllers\ErrorController;

class Router {
    public static function dispatch(string $uri, string $method, array $routes): void {
        $routeMap = $routes[$method] ?? [];

        // 1. Exact match (fast path — all Phase 1 routes, no regex overhead)
        if (isset($routeMap[$uri])) {
            [$controllerName, $action, $middleware] = array_pad($routeMap[$uri], 3, null);
            self::run($controllerName, $action, $middleware, $method, []);
            return;
        }

        // 2. Dynamic segment match — {param} placeholders
        foreach ($routeMap as $pattern => $handler) {
            if (strpos($pattern, '{') === false) {
                continue; // skip static routes already checked above
            }
            $regex = preg_replace('/\{([a-zA-Z_][a-zA-Z0-9_]*)\}/', '(?P<$1>[^/]+)', $pattern);
            $regex = '#^' . $regex . '$#';
            if (preg_match($regex, $uri, $matches)) {
                // Keep only named captures (remove numeric keys from preg_match result)
                $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
                [$controllerName, $action, $middleware] = array_pad($handler, 3, null);
                self::run($controllerName, $action, $middleware, $method, $params);
                return;
            }
        }

        (new ErrorController)->notFound();
    }

    private static function run(
        string $controllerName,
        string $action,
        ?string $middleware,
        string $method,
        array $params
    ): void {
        if ($middleware === 'auth') {
            AuthMiddleware::handle();
        }
        if ($method === 'POST') {
            CsrfMiddleware::validate();
        }
        $fqcn       = "App\\Controllers\\{$controllerName}";
        $controller = new $fqcn();
        $controller->$action($params);
    }
}
```

**IMPORTANT:** The controller action signature changes — actions now receive `array $params` as first argument. This affects ALL existing controllers. Update existing controller actions to accept (and ignore if unused) the `$params` argument:
- `HomeController::index(array $params = [])`
