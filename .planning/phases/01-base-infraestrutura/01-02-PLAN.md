**app/Models/BaseModel.php** — exactly:
```php
<?php
declare(strict_types=1);

namespace App\Models;

class BaseModel {
    protected \PDO $db;

    public function __construct() {
        static $pdo = null;
        if ($pdo === null) {
            $cfg = require dirname(__DIR__, 2) . '/config/database.php';
            $dsn = "mysql:host={$cfg['host']};dbname={$cfg['name']};charset=utf8mb4";
            $pdo = new \PDO($dsn, $cfg['user'], $cfg['pass'], [
                \PDO::ATTR_ERRMODE            => \PDO::ERRMODE_EXCEPTION,
                \PDO::ATTR_DEFAULT_FETCH_MODE => \PDO::FETCH_ASSOC,
                \PDO::ATTR_EMULATE_PREPARES   => false,
            ]);
        }
        $this->db = $pdo;
    }

    protected function query(string $sql, array $params = []): \PDOStatement {
        $stmt = $this->db->prepare($sql);
        $stmt->execute($params);
        return $stmt;
    }
}
```

Critical: ATTR_EMULATE_PREPARES must be false (RESEARCH.md Pitfall 5 — silent security regression if omitted).

**app/Middleware/CsrfMiddleware.php** — exactly:
```php
<?php
declare(strict_types=1);

namespace App\Middleware;

class CsrfMiddleware {
    public static function token(): string {
        if (empty($_SESSION['csrf_token'])) {
            $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
        }
        return $_SESSION['csrf_token'];
    }

    public static function validate(): void {
        $token = $_POST['csrf_token'] ?? '';
        if (!hash_equals($_SESSION['csrf_token'] ?? '', $token)) {
            http_response_code(403);
            (new \App\Controllers\ErrorController)->forbidden();
            exit;
        }
    }
}
```

Critical: hash_equals() MUST be used — not ===. bin2hex(random_bytes(32)) MUST be used — not uniqid().

**app/Helpers/Session.php** — exactly:

```php
<?php
declare(strict_types=1);

namespace App\Helpers;

class Session {
    public static function start(): void {
        if (session_status() === PHP_SESSION_ACTIVE) {
            return;
        }
        ini_set('session.cookie_httponly', '1');
        ini_set('session.use_strict_mode', '1');
        ini_set('session.cookie_samesite', 'Lax');
        session_save_path(ROOT_PATH . '/storage/sessions');
        session_start();
    }
}
```

ROOT_PATH is defined in public/index.php (Plan 03) before Session::start() is called.

```php
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| $_POST['csrf_token'] | User-controlled value compared to server session token |
| $_SESSION['role'] | Server-side value — must never be set from user input |
| User email/password in POST | User-controlled inputs to auth controller (Plan 03) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | CsrfMiddleware::validate() | mitigate | hash_equals() prevents timing attacks; random_bytes(32) makes token unguessable (RESEARCH.md Don't Hand-Roll) |
| T-02-02 | Elevation of Privilege | AuthMiddleware::handle() | mitigate | Checks $_SESSION['role'] === 'admin' — not just presence of user_id. Both must be true. |
| T-02-03 | Tampering | SQL injection via UserModel | mitigate | All queries use BaseModel::query() with prepare()/execute() and named parameters; ATTR_EMULATE_PREPARES=false |
| T-02-04 | Tampering | XSS via View::render() | mitigate | $e() closure available in every template; EXTR_SKIP prevents attacker-supplied $e override |
| T-02-05 | Elevation of Privilege | Session fixation | mitigate | AdminAuthController (Plan 03) must call session_regenerate_id(true) on successful login |
| T-02-06 | Information Disclosure | Session data in shared /tmp | mitigate | session_save_path(ROOT_PATH . '/storage/sessions') isolates sessions to project directory |
