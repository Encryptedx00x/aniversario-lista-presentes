**app/Helpers/Upload.php** — exactly:
```php
<?php
declare(strict_types=1);

namespace App\Helpers;

/**
 * Upload security scaffold (SEC-05).
 * Phase 1 provides validation helpers only — no file move logic yet.
 * Phase 3+ will add the full upload flow using these methods as gates.
 */
class Upload {
    /**
     * Validate the real MIME type of an uploaded file using libmagic.
     * NEVER trust $_FILES['type'] — it is user-supplied and trivially spoofed.
     *
     * @param string   $tmpPath      Value of $_FILES['field']['tmp_name']
     * @param string[] $allowedMimes e.g. ['image/jpeg', 'image/png', 'image/webp']
     */
    public static function validateMime(string $tmpPath, array $allowedMimes): bool {
        $finfo    = finfo_open(FILEINFO_MIME_TYPE);
        $mimeType = finfo_file($finfo, $tmpPath);
        finfo_close($finfo);
        return in_array($mimeType, $allowedMimes, strict: true);
    }

    /**
     * Validate the file extension against a whitelist.
     * Use alongside validateMime() — extension alone is insufficient.
     *
     * @param string   $filename  Original filename from $_FILES['field']['name']
     * @param string[] $whitelist e.g. ['jpg', 'jpeg', 'png', 'webp']
     */
    public static function validateExtension(string $filename, array $whitelist): bool {
        $ext = strtolower(pathinfo($filename, PATHINFO_EXTENSION));
        return in_array($ext, $whitelist, strict: true);
    }
}
```

Both MIME and extension checks use strict comparison (third argument `true` / `strict: true`).

**app/Controllers/AdminAuthController.php** — exactly:
```php
<?php
declare(strict_types=1);

namespace App\Controllers;

use App\Models\UserModel;
use App\Helpers\{View, Flash};

class AdminAuthController {
    public function loginForm(): void {
        View::render('admin/login', ['title' => 'Admin Login', 'layout' => 'admin_bare']);
    }

    public function loginPost(): void {
        $email    = trim($_POST['email']    ?? '');
        $password =      $_POST['password'] ?? '';

        if ($email === '' || $password === '') {
            Flash::set('error', 'Preencha e-mail e senha.');
            header('Location: /admin/login');
            exit;
        }

        $user = (new UserModel)->findByEmail($email);

        // SEC-04: password_verify against stored hash; also confirm admin role
        if ($user && $user['role'] === 'admin' && password_verify($password, $user['password_hash'])) {
            session_regenerate_id(true);          // SEC-04/SEC-06: prevent session fixation
            $_SESSION['user_id'] = $user['id'];
            $_SESSION['role']    = 'admin';
            $_SESSION['name']    = $user['name'];
            unset($_SESSION['csrf_token']);        // Force CSRF token regeneration after privilege change
            header('Location: /admin/dashboard');
            exit;
        }

        // Generic error — do NOT reveal whether email or password was wrong (SEC-06)
        Flash::set('error', 'Credenciais inválidas.');
        header('Location: /admin/login');
        exit;
    }

    public function dashboard(): void {
        // AuthMiddleware already verified $_SESSION['role'] === 'admin'
        View::render('admin/dashboard', [
            'title'  => 'Dashboard',
            'layout' => 'admin',
        ]);
    }

    public function giftsStub(): void {
        // D-05: stub route — renders admin/stub view (Plan 04) with section title
        View::render('admin/stub', [
            'title'   => 'Presentes',
            'layout'  => 'admin',
            'section' => 'Presentes',
        ]);
    }

    public function logout(): void {
        session_destroy();
        header('Location: /admin/login');
        exit;
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| $_POST['email'] / $_POST['password'] | User-controlled inputs to loginPost — never echoed, never interpolated into SQL |
| $_POST['csrf_token'] | User-controlled, compared via hash_equals() in CsrfMiddleware before loginPost runs |
| $_SERVER['REQUEST_URI'] | User-controlled URI — only matched against static route table, never eval'd |
| $_SESSION['role'] | Server-side only — never set from user input, only from verified DB row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | AdminAuthController::loginPost | mitigate | password_verify() against bcrypt hash; session_regenerate_id(true) prevents session fixation (SEC-04) |
| T-03-02 | Information Disclosure | AdminAuthController::loginPost error message | mitigate | Generic "Credenciais inválidas." — does not reveal which field was wrong (SEC-06) |
